お絵かき水族館

みんなの絵が、海を泳ぐ。

お絵かき水族館は、みんなが描いた生き物をオンラインの水槽に泳がせることができるWebサービスです。

好きな魚や海の生き物を描いたり、紙に描いた絵を写真に撮ったりして投稿すると、自分の作品が水族館の中を泳ぎ始めます。

イベントや展示会、学校行事など、みんなで楽しめる参加型の水族館を作ることを目指しています。

⸻

主な機能

1. 主催者画面

イベントや開催場所ごとに専用の識別コードを設定できます。

識別コードを入力すると、以下のURLが自動生成されます。

* お絵かき投稿用URL
* 水族館の表示用URL
* 設定・管理用URL

同じ識別コードを使うことで、同じ水槽に作品を集められます。

2. お絵かき投稿

ブラウザ上で自由に生き物を描いて投稿できます。

* 9色のカラーパレット
* ペン
* 消しゴム
* ひとつ戻す
* ぜんぶ消す
* 生き物の名前の設定

描いた作品は背景を自動で透過して、水槽に投稿されます。

3. 写真投稿

紙に描いた生き物を撮影して投稿することもできます。

* カメラで撮影
* 画像ファイルの選択
* 背景の自動透過
* 送信前のプレビュー
* 生き物の名前の設定

デジタルで描くのが苦手な人でも参加できます。

4. デジタル水族館

投稿された生き物たちが、画面の中をゆったりと泳ぎます。

* 生き物の自動表示
* ゆったりとした遊泳アニメーション
* 水中をイメージした背景
* 泡のアニメーション
* 投稿作品の自動更新

会場のスクリーンなどに表示して、みんなの作品を楽しめます。

5. 設定・生き物管理

主催者向けの管理画面も用意しています。

* 投稿用QRコードの生成
* 投稿方法の切り替え
* 投稿された生き物の一覧表示
* 生き物の名前・投稿日時の確認
* 投稿作品の削除

使い方

主催者

1. 主催者画面を開く
2. イベントなどの識別コードを入力
3. URLを作成
4. 投稿用URLを参加者に共有
5. 表示用URLを会場のスクリーンなどで開く

参加者

1. 投稿用URLまたはQRコードを開く
2. 画面に直接絵を描くか、紙に描いた絵を撮影する
3. 好きな名前を設定する
4. 投稿する

投稿された作品は、水族館の画面に表示されます。

スマートフォンでも投稿しやすく、スクリーンでも見やすい画面を目指しています。
